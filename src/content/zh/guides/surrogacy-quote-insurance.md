代孕报价是一份工作清单：筛查、用药、移植、代孕者的报酬、法律文件。每一项对应一个数字，数字相加，得出一份可以抄进一栏之内的合计。

保险并非清单。它是对尚未发生之事的一组承诺，而其赔付，在事件之后由一家未曾参与签约的机构决定。报价之所以可以完整、却仍只描述了这项安排一半的成本，原因即在于此：报价止于治疗结束，而代价最重的账单往往在其后送达。

以下内容不陈述任何地区的具体保障范围。保障范围取决于保单号、所在国家与日期；一份通用指南若写出具体数字，即为编造。此处所能提供的是问题的结构，以及每一问应由何方作答。

## 三份保单，且均非报价本身

多数安排之中同时存在三份互不相同的保障，而三者之间的联系并不紧密。

- **代孕者本人的医疗保险**。由她持有，在您进入这一安排之前即已订立，其条款如何规定妊娠、如何规定代孕、由谁支付何项费用，均以其保单为准。
- **为本次妊娠订立的保单**。有时由项目方安排，有时由代孕者自行办理，也常常正是报价中笼统标为「保险」的那一条。
- **孩子本人的保障**。若确有保障，其起始时点由保单写明：出生之时、出院之时、提出申请之时，或某个更晚的日期。

三者鲜少共用同一保险方、同一生效日，或同一套关于「并发症」的定义。故凡就保险发问，首先须问的是：您所问的是三者中的哪一份。以一句话作答的报价，实际未回答其中任何一份。

## 出生之时才开启的窗口

出生之前只有一位患者，患者即代孕者。出生之后有两位，其中一位没有既往保单记录、没有会员编号，在许多安排里甚至没有一份属于她本人的档案。

这一情形是否改变什么、自哪一时点改变，写在保单里而非写在报价里。应索取的是一句条款，而非一段概述：即明确规定孩子保障自何时开始、须满足何种条件方可适用的那一条。若答复为「孩子有保障」，所回答的是宣传问题；可用的答复之中应含日期、条件，以及一份可以指认的文件。

## 报价按设计不予写明的部分

报价由撰写者所能掌控的项目构成。保费、免赔额与免责条款通常由他方掌控，这正是其常见缺席的寻常原因。可与任何方案逐项核对的内容如下：

- 保费由谁支付、支付多少个月，以及妊娠超过所报期限时的处理方式。
- 免赔额与共同保险的比例，以及该项由项目方承担，抑或由托管账户承担。
- 在此处而非在一般情形下才会显现的免责事项：多胎妊娠、早产、代孕者既有的疾病，以及在保单网络之外接受的医疗。
- 代孕者本人保单对于「为他人生育」这一妊娠的规定，此一条款最易使双方同时意外。
- 理赔被拒时的处理方式。所问并非保单是否宽厚，而是答复为否之时，资金由谁持有。

最后一条应最先阅读。其余各条说明的是安排本应如何运作；这一条说明的是它未能如此运作时，由谁付款。

## 一页四栏

使上述内容具体化的方法，须占用一个下午。四栏，每一事件占一行：

| 事件 | 由谁支付 | 哪份文件如此规定 | 由谁签署 |
| --- | --- | --- | --- |
| 代孕者筛查 | | | |
| 用药与监测 | | | |
| 移植 | | | |
| 可存活期之前的住院 | | | |
| 分娩 | | | |
| 出生后孩子的医疗 | | | |
| 超出计划的停留 | | | |

前两栏是所有人都会讨论的内容；后两栏才是争议发生时据以判断的内容。一方可以在电话里描述一项付款，却无法指出相应条款、相应文件，或同意该项付款之人，而这一「无法指出」本身即是结论。若两份文件相互矛盾，您所找到的是一项应提交律师、而非提交机构的问题。

## 五个问题，以及各自的答复方

| 问题 | 应向何方提出 | 可用的答复应包含 |
| --- | --- | --- |
| 妊娠期间由哪份保单承保代孕者，其免责范围为何？ | 代孕者的保险方，经机构转达 | 保单号与免责条款，而非概述 |
| 孩子的保障自何时开始，以何条件为前提？ | 订立该保单的一方 | 相应条款，以及该保单的生效日期 |
| 保费、免赔额与共同保险各为多少，由谁支付？ | 项目方 | 一份列明收款方的明细表 |
| 理赔被拒时由谁支付，自哪个账户支付？ | 项目方与托管账户管理人 | 具名账户与放款条件 |
| 上述哪些文件可在签约之前查阅？ | 以上各方 | 文件副本，而非文字描述 |

第四问应分别向项目方与托管账户管理人各提一次，再作比对。答复不一致之处，即为本页所述之缺口。

## 备用金不是保单

报价中的备用金是一项预算，而预算是一个终将被花掉的数字。保单所转移的，是一项无法预估上限的账单。二者各有其位，且不能相互替代：按典型结果设定的备用金，在结果一旦不再典型之时，即不再是备用金。

这一区别亦体现于方案的写法。将保险列为一项成本条目的报价，所标价的是管理费用；它并未告知您，某一笔住院费用应由谁承担，而该条目看上去所回答的正是此问。

## 本页无法解决的部分

某一国家存在哪些保单、其免责范围为何、非本地居民能否投保：上述均非一份通用页面所能确定，且答案随保单年度而变。您自身在法律与财务上的处境，同样不是一份指南所能读出的。

此处能够确定的，是问题的结构、每一问的答复方，以及提问的次序：先取条款，再谈合计。

## 常见问题

**报价中的保险一项，是否为孩子提供保障？**

该条目通常写明的是某份保单，而非保障范围。应索取启动孩子保障的条款，及其所依据的日期。在此之前，标为「保险」的一行，并未就孩子说明任何事情。

**是否可以自行安排保险？**

有时可以，而能否成立取决于时点。是否可以提出申请、由谁提出，以及在哪个环节之后不再受理，均属应向保险方与相关国家提出的问题；且值得在移植之前提出，而非在账单到达之后。

**提高备用金是否为更简单的答案？**

它回答的是账单，而非问题。备用金所吸收的是一项已经向您收取的费用；它并不告知您，该项费用原本应由谁承担。而义务的归属，正是保单、托管条款或合同存在的理由。
