代孕报价是一张活清单：筛查、用药、移植、代孕者的报酬、法律文件。每一项对上一个数字，数字一加，出来一个能抄进一栏的合计。

保险不是清单。它是对还没发生的事的一组承诺，而赔不赔，要等事情发生之后由一家没参与签约的机构来定。所以报价可以是完整的，却仍然只说了这项安排一半的成本：报价止于治疗结束，最重的账单往往在其后寄到。

以下不写任何地区的具体保障范围。范围取决于保单号、国家和日期；通用指南写出具体数字，就是编的。这里能给的是问题的结构，以及每一问该由谁来答。

## 三份保单，没有一份是报价

多数安排里同时有三份互不相同的保障，彼此之间联系不紧。

- **代孕者自己的医疗保险**。在她手上，在您进入这项安排之前就订好了。它怎么写妊娠、怎么交代孕、由谁付哪一项，都以保单为准。
- **为这次妊娠定的保单**。有时项目方安排，有时代孕者自己办，也常常就是报价里笼统写成「保险」的那一行。
- **孩子自己的保障**。如果真有，从哪天开始由保单写明：出生、出院、提出申请，还是某个更晚的日子。

三者很少是同一家保险方、同一个生效日，也很少共用同一套「并发症」的定义。所以问保险，第一句该问的是：您问的是这三份里的哪一份。用一句话回答的报价，其实一份都没答。

## 出生那天才打开的窗口

出生之前只有一个患者，就是代孕者。出生之后有两个，其中一个没有既往保单记录、没有会员编号，很多安排里甚至没有一份给他建的档案。

这件事到底会不会变、从哪一刻变，写在保单里，不写在报价里。要的是一条条款，不是一段概述：写明孩子的保障从哪天开始、要满足什么才用得上。如果答复是「孩子有保障」，那答的是宣传问题。能用的答复里得有日期、条件，和一份能指出名字的文件。

## 报价本来就不打算写明的部分

报价由写它的那一方能掌控的项目组成。保费、免赔额和免责条款大多握在别人手里，这就是它们常常缺席的原因，很平常。下面这些可以拿任何方案逐条核对：

- 保费谁付、付几个月，妊娠超出所报期限怎么算。
- 免赔额和共同保险的比例，这一项归项目方还是托管账户。
- 只在代孕这里才显形的免责项：多胎、早产、代孕者原有的病，以及在保单网络之外看的病。
- 代孕者自己那份保单怎么规定「替别人生」这种妊娠。这一条最容易让两边同时愣住。
- 理赔被拒之后怎么办。问的不是这份保单厚不厚道，而是它说不的时候，钱在谁手上。

最后一条该最先读。其余几条讲的是安排本来该怎么走；这一条讲的是它没走通时谁付钱。

## 一页四栏

要把它落到实处，得花一个下午。四栏，每个事件一行：

| 事件 | 由谁支付 | 哪份文件如此规定 | 由谁签署 |
| --- | --- | --- | --- |
| 代孕者筛查 | | | |
| 用药与监测 | | | |
| 移植 | | | |
| 可存活期之前的住院 | | | |
| 分娩 | | | |
| 出生后孩子的医疗 | | | |
| 超出计划的停留 | | | |

前两栏是所有人都会聊的；后两栏才是出事之后拿来判断的。电话里描述一笔付款容易，指出是哪一条、哪份文件、谁同意的，就指不出来了；而指不出来，本身就是结论。两份文件互相打起来，您手上就是一个该交给律师、而不是交给机构的问题。

## 五个问题，五个答复方

| 问题 | 应向何方提出 | 可用的答复应包含 |
| --- | --- | --- |
| 妊娠期间由哪份保单承保代孕者，其免责范围为何？ | 代孕者的保险方，经机构转达 | 保单号与免责条款，而非概述 |
| 孩子的保障自何时开始，以何条件为前提？ | 订立该保单的一方 | 相应条款，以及该保单的生效日期 |
| 保费、免赔额与共同保险各为多少，由谁支付？ | 项目方 | 一份列明收款方的明细表 |
| 理赔被拒时由谁支付，自哪个账户支付？ | 项目方与托管账户管理人 | 具名账户与放款条件 |
| 上述哪些文件可在签约之前查阅？ | 以上各方 | 文件副本，而非文字描述 |

第四问要分别问项目方和托管账户管理各一次，再对一遍。两边答的不一样的地方，就是这一页在说的那个缺口。

## 备用金不是保单

报价里的备用金是一笔预算，而预算就是一个迟早会被花掉的数字。保单转走的是那张没有上限的账单。两者各有各的位置，不能互相顶替：按典型结果设的备用金，结果一旦不典型，就不再是备用金了。

这个区别也写在方案的写法里。把保险列成一条成本的报价，标的是管理费；它没告诉您某一笔住院费该谁承担，而这一行看上去答的正是这个问题。

## 本页解决不了的部分

某个国家有哪些保单、免责范围多大、非本地居民能不能投，通用页面定不了，答案还随保单年度变。您自己在法律和财务上的处境，也不是一份指南读得出来的。

这里能定的是问题的结构、每一问的答复方，和提问的次序：先拿条款，再谈合计。

## 常见问题

**报价里那条保险，保不保孩子？**

这一行通常写的是某一份保单，不是保障范围。要启动孩子保障的那条条款，和它依据的日期。在这之前，写着「保险」的那一行，关于孩子什么也没说。

**保险可以自己安排吗？**

有时可以，成不成看时点。能不能申请、谁来申请、过了哪一步就不再受理，这些都要问保险方和相关国家；而且值得在移植之前问，不要等账单到了再问。

**把备用金提高，是不是更省事的答案？**

它答的是账单，不是问题。备用金吸收的是一笔已经向您收过的费，它不告诉您这笔钱本来该谁出。而义务归谁，正是保单、托管条款或合同存在的理由。
